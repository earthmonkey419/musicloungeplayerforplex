SEARCH

The search bar on the Player home page searches the full library as text is entered. Results load in pages while scrolling. Matching albums, if any, appear in a row above the track results.

Two rows of pills below the search bar provide quick filtering without typing. Moods (Funk, Soul, Jazz, Dance, Chill, Rock) group tracks by vibe rather than strict genre. Genres reflects the library's actual genre tags — MusicMind's own data when connected, otherwise a smaller general set. An "Instrumental only" toggle is available when MusicMind is connected.

On any result row: ▶ plays the item immediately. ⋯ opens an options menu — see The ⋯ Menu.

BROWSE

The Browse tab organizes the library by structure: Artists, Albums, or Tracks. Each view supports sorting (name, recently added, and for albums, artist or year). When sorted by name, an A-Z quickbar allows jumping directly to a letter.

Selecting an artist displays their albums, newest first. Selecting an album displays its full tracklist, with the same row actions as search results, plus a Play Album button that queues the album in track order.

THE ⋯ MENU

The ⋯ button appears on tracks, albums, and playlists throughout the app — search results, Browse, and playlist views — and opens the same set of options for that item.

Play Next inserts the item immediately after the current track, ahead of the rest of the queue. Add to Queue appends it to the end of the queue. Add to Playlist opens the playlist picker. Start a Room and Share a Link open those flows pre-filled with the selected item — see Room Mode and Share Mode. For tracks, Go to Album navigates to the track's album page. For tracks and albums, Start Radio starts a station based on that item — see Radio.

On narrow screens, Add to Queue and Add to Playlist are available only through this menu; Play and ⋯ remain visible as standalone buttons.

RADIO

Radio plays a continuous station that doesn't run out. Choose Start Radio from the ⋯ menu on any track or album, or press Random Radio on the search page. A station begins with the track (or a track from the album) and continues with similar music; when only a few tracks remain in the queue, more are added automatically. A small badge shows the station name — press ✕ on it to stop.

A station ends when you start something else playing, such as pressing Play on an album. Add to Queue and Play Next work normally while a station is running. Shuffle is turned off when a station starts so new tracks stay in order.

With MusicMind connected, similarity comes from your library's tags plus measured tempo and key. Without it, radio uses Plex's sonic analysis if your server has it (Plex Pass required). If neither is available, Start Radio is hidden and only Random Radio is offered, drawing from a random mood.

PLAYLISTS

Two types of playlists are supported.

Native playlists exist only within MusicLounge Player. Tracks can be added from search or Browse, reordered by dragging, and removed at any time. Export to Plex creates a corresponding playlist in the Plex library, prefixed with MusicLounge- for identification.

Plex-synced playlists are existing Plex playlists imported for access here. They are read-only and refresh to match Plex on each view. Changes must be made in Plex directly.

QUEUE & NOW PLAYING

The queue persists across page reloads and navigation. The ☰ button in the player bar opens the full queue view, where tracks can be selected to jump to, reordered by dragging, or removed.

Selecting the album art or track title/artist in the player bar (not the control buttons) opens the expanded Now Playing view, with larger art, a draggable progress bar, and full transport controls. In landscape orientation, this view uses a side-by-side layout.

Playback continues uninterrupted when navigating between Player, Browse, and Playlists. On iOS, AirPlay is supported through Safari's native audio controls; no additional configuration is required.

ROOM MODE

Room Mode enables a shared listening session. Starting a room from the Player home page generates a join code and QR code. Guests who join add to a single shared queue and see the same now-playing track; no account is required to join.

Audio plays through the host's device. Guests select content but do not stream it themselves, making this suited for a shared physical space.

SHARE MODE

Share Mode generates a private, time-limited link to a track, album, artist, or playlist, for sending to an individual recipient rather than hosting a live session. An expiration period can be set, and the link can be copied or, if SMTP is configured, emailed directly. Emailed links include a thumbnail of the shared content.

The recipient receives a standalone player for the shared content, playing on their own device. It does not affect the host's queue or listening history.

LAST.FM SCROBBLING

When Last.fm is configured, connecting an account from Settings is a one-time step. Tracks played in Player, Playlists, or Browse are reported as "now playing" and scrobbled automatically once sufficiently listened to, per Last.fm's own criteria. Skipped tracks are not scrobbled.

Room Mode and Share Mode playback is never scrobbled, regardless of connection status.

INSTALL AS AN APP

MusicLounge Player can be installed to a phone's home screen, providing a dedicated icon and a standalone window without browser chrome.

iOS (Safari): tap the Share button, then "Add to Home Screen."

Android (Chrome): tap the menu (⋮), then "Add to Home Screen" or "Install app."

Known limitation (iOS): when the installed app is backgrounded during playback, the current track continues playing, but subsequent tracks do not begin automatically until the app returns to the foreground. This does not occur in a standard Safari browser tab. For uninterrupted background playback across a queue, use a browser tab rather than the installed app.
